# Instrucciones para Claude en este repo

Ve `README.md` para qué es este proyecto, y `SETUP.md` para cómo se arma y despliega desde cero.

## Mantener `SETUP.md` al día

Si algún cambio introduce una herramienta, cuenta o paso nuevo al proceso de construir/desplegar el proyecto (un servicio nuevo, una variable de entorno nueva, un cambio en el flujo de trabajo con git/Vercel, etc.), actualiza `SETUP.md` en el mismo commit -no lo dejes para después.

`SETUP.md` es la referencia para alguien que arranque un proyecto nuevo o reconstruya este desde cero, así que debe reflejar el proceso REAL y actual, no el original.
